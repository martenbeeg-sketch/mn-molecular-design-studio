# Scientific pipeline regression tests

Phase 2 adds explicit measurement outcomes, provenance-qualified final evidence and
optional candidate selection. See [Scientific results and candidate selection](scientific-results-selection.md)
for API/UI behavior, compatibility changes, real execution evidence and rerun commands.

Use the existing `mn-molecular-design-studio` Conda Python. CPU pytest never launches GPU tests unless `MDS_GPU_TESTS=1` is set. Mark real single-engine inference with `gpu`, and real multi-stage inference with `gpu_e2e`. Neither marker authorizes downloads or large campaigns.

```bash
python -m pytest tests/test_scientific_contracts.py -q
MDS_GPU_TESTS=1 MDS_TEST_GPU=0 python -m pytest tests/test_scientific_gpu.py -v -s
```

`MDS_GPU_ARTIFACTS` selects an artifact directory (default `.tmp/gpu-tests`). Each test retains runtime/device/image metadata and production job logs, effective parameters, normalized candidates and structures. `MDS_TEST_GPU` selects a device from `nvidia-smi`. Tests use installed reference caches and images. A missing prerequisite is SKIP; an inference or scientific-contract error after launch is FAIL. Preparation-only checks are not GPU inference. No comparison requires identical coordinates or numerical scores across devices.

These checks establish computational integration and scientific data handling, not experimental predictive validity.

## Verified implementation — 27 October 2026

F1 and F2 were reproduced with failing CPU regressions before repair. The branch was clean on `fix/scientific-pipeline-validation`; no new branch was created and nothing was pushed.

RFD4 component tasks now retain exact protein sequences, explicit target/binder roles, an original-to-prediction component/chain map, per-chain MSA policy, source-candidate lineage and reference constraints. Source structures and component sequences must agree. All published prediction protein sequences/chains are checked against the request. Single-atom ions are retained. Structure-backed CCD conversion verifies the installed CCD heavy-atom inventory. Boltz's generic `LIG` labels are restored in a derived identity structure after atom verification; original outputs and sample-specific confidence/PAE files remain available.

ipSAE no longer invents A/B assignments. Rosetta explicitly rejects interfaces outside its one-binder/one-target contract. Missing/non-finite measurements and analysis errors cannot become successful analysis jobs or passing filters. Measurement records retain structure, source candidate, chain roles, PAE file/cutoffs or Rosetta parameters, and status.

The VHH starter now accepts BindCraft2 scaffold-mode empty length and routes original generator sequences through SAbR annotation to Boltz-2. It performs no implicit general ProteinMPNN redesign. Default old VHH drafts migrate to this behavior; explicitly configured redesign nodes are retained. Explicit SAbR/AbMPNN redesign fixes frameworks, unselected CDRs and every native cysteine. Its output must agree with its FASTA, fixed residues, and unchanged target chains. Native ESMFold2 VHH output is checked against the exact sampled framework/CDR prompt and its complex structure.

### Remaining boundaries

Rosetta interface scoring supports one protein binder and one protein target chain; multichain targets are reported as unsupported. The interface ipSAE path supports one binder with an explicit target group; multiple binders are rejected. The multichain heterogeneous GPU test checks prediction/component handling, not Rosetta support for that assembly.

Modified amino acids/nucleotides, explicit non-disulfide inter-residue bonds, PDB CONECT topology, unavailable/custom CCDs, incomplete CCD atom inventories, and structure-backed SMILES without verified source atom/bond mapping are explicitly rejected by the RFD4 handoff. Waters remain outside molecular component import. The generated RFD4 target retained its exact sequence; inspection measured 0.374 Å fitted C-alpha RMSD and 0.901 Å maximum internal C-alpha distance deviation under coordinate-group conditioning. Exact target-coordinate preservation was not established. Canonical disulfides and generator constraints remain reference information; no bond-geometry, stereochemistry or catalytic-geometry validation is claimed. CCD atom identity checks do not establish chemical stability or affinity. GPU DNA/RNA cases were not run in this task.

No wet-lab or prospective predictive-validity benchmark was performed. No large screening/design campaign or model download was launched. The broader pipeline catalogue was not reorganized.
