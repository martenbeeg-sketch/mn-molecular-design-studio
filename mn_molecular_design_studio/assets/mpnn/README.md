# MPNN input examples

- `9F6O.pdb`: RCSB structure 9F6O, retrieved from
  https://files.rcsb.org/download/9F6O.pdb. Tamarind's ProteinMPNN example uses
  nanobody chain B, designing B26–32, B52–56 and B95–102 (20 residues).
- `1BC8.pdb`: RCSB structure 1BC8, retrieved from
  https://files.rcsb.org/download/1BC8.pdb. Protein chain C is designed while the
  DNA chains A/B provide LigandMPNN atomic context. This is also an upstream
  LigandMPNN example structure.

The application copies examples into the current user's input folder before
submission. The source coordinates are not modified.
