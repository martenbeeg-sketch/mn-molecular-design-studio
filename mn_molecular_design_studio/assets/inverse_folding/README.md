# Input examples

- `3HTN.pdb`: protein coordinates from RCSB entry 3HTN, downloaded from
  https://files.rcsb.org/download/3HTN.pdb. Residues were numbered consecutively
  within each chain, matching ESM-IF1's input example convention. The example
  designs A62–70. No inference was used to prepare this file.
- `1CRN.pdb`: RCSB crambin entry 1CRN, downloaded from
  https://files.rcsb.org/download/1CRN.pdb. This is the structure shown by
  Tamarind's Caliby example. Loading that example omits C and G, as its form does.
  BoltzGen Inverse Folding also uses 1CRN as a small arbitrary-structure example.
