AutoDock Vina example inputs
===========================

1IEP (ABL kinase with imatinib) and PubChem CID 5291 (imatinib) are the
public scientific example pair used by Tamarind's AutoDock Vina page.
Files retrieved from https://app.tamarind.bio/1iep.pdb and
https://app.tamarind.bio/Conformer3D_COMPOUND_CID_5291.sdf on 2026-10-19.

Primary records: https://www.rcsb.org/structure/1IEP and
https://pubchem.ncbi.nlm.nih.gov/compound/5291.
imatinib.json stores the SDF's RDKit-derived SMILES for loading the example
without requiring chemistry conversion in the UI process.
